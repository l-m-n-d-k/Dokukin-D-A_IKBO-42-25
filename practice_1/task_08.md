# Задача 8. Архивация файлов заданного расширения

## Задание

Написать программу, которая находит все файлы в данном каталоге с расширением, указанным в качестве аргумента, и архивирует их в архив `tar`.

## Код программы

```bash
#!/usr/bin/env bash
ext="${1#.}"; dir="$2"; out="${3:-archive.tar}"
[[ -n "$ext" && -n "$dir" ]] || { echo "Использование: $0 <расширение> <каталог> [выходной_архив]" >&2; exit 1; }
[[ -d "$dir" ]] || { echo "Ошибка: каталог $dir не найден" >&2; exit 1; }
files=$(find "$dir" -type f -name "*.$ext")
[[ -n "$files" ]] || { echo "Файлов .$ext в $dir не найдено"; exit 1; }
printf '%s\n' "$files" | tar -cf "$out" -T -
echo "Создан архив: $out ($(tar -tf "$out" | wc -l) файлов)"
```

## Проверка

Тестовый каталог `dup` содержит файлы `*.txt`:

```text
$ ./task8 txt dup out.tar
Создан архив: out.tar (4 файлов)

$ tar -tf out.tar
dup/only.txt
dup/f3.txt
dup/b/f2.txt
dup/a/f1.txt
```

Все 4 файла с расширением `.txt` попали в архив; файлы других расширений — нет.
