# Задача 1. Отсортированный список пользователей из `/etc/passwd`

## Задание

Вывести отсортированный в алфавитном порядке список имён пользователей из файла `passwd` (понадобится `grep`).

## Решение

```bash
grep -oE '^[^:]+' /etc/passwd | sort
```

## Пояснение

- Строка записи файла `/etc/passwd` имеет вид `имя:x:uid:gid:...`. Имя пользователя — первый элемент до двоеточия.
- `grep -oE '^[^:]+'` выводит только совпавшие части строк: начальный фрагмент из любых символов, кроме `:` (`-o` — только совпадение, `-E` — расширенные регулярные выражения).
- `sort` упорядочивает полученный список в алфавитном порядке.

## Пример вывода

```text
abrt
adm
apache
avahi
bin
chrony
clevis
colord
...
sshd
sync
systemd-coredump
tss
unbound
wsdd
```
